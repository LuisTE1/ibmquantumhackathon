# Documentación de Quantum Files

Esta carpeta reúne la documentación vigente de la PWA y conserva registros históricos del prototipo anterior. La especificación del producto web y sus pruebas se deben contrastar con `web/public/`, `web/api/` y `tests/test_web.py`.

## Documentos vigentes

- [PEDAGOGIA.md](PEDAGOGIA.md) — público propuesto, objetivos, secuencia didáctica y relación entre estadística y medición.
- [ARQUITECTURA.md](ARQUITECTURA.md) — frontend PWA, API Python/Qiskit, simulador alternativo y persistencia.
- [VALIDACION.md](VALIDACION.md) — pruebas técnicas ejecutables y protocolo de evaluación educativa.
- [LIMITACIONES.md](LIMITACIONES.md) — alcance, riesgos de interpretación y pendientes.
- [FUENTES.md](FUENTES.md) — bibliotecas, documentación técnica, referencias pedagógicas, arte y herramientas.
- [GUION-PITCH.md](GUION-PITCH.md) — presentación de 2:30 a 3:00 minutos.
- [ENTREGA.md](ENTREGA.md) — lista para preparar el envío al portal del evento.
- [ESTADO-INTEGRACION.md](ESTADO-INTEGRACION.md) — diferencias entre la PWA y el sistema Streamlit heredado, verificación del despliegue y correcciones propuestas.
